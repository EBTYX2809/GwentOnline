# Выбор веб-стека

**Контекст:** пока не выбран ни фронтенд-фреймворк, ни то, на чём будет жить бэкенд. Это первый
настоящий развилочный вопрос веб-порта — от него зависит форма остальных веток (см.
`todo/server-rework.md`, `todo/database-and-accounts.md`, `todo/deployment.md`, которые
конкретизируются уже после этого выбора). Разбирать предметно, с учётом [[user-background]] —
нулевой опыт веба, приоритет мейнстримным и хорошо документированным вариантам.

## Что нужно разобрать

- **Фронтенд:** React / Vue / Svelte (или другое) — сравнить конкретно под задачи этого проекта, а
  не абстрактно:
  - адаптивная раскладка сетки карт (см. `todo/ui-asset-reuse-and-layout.md`);
  - drag&drop карт;
  - WebSocket-клиент для связи с сервером в реальном времени.
- **Бэкенд:** держаться C#/.NET (переиспользуя опыт и, возможно, куски логики из текущего
  серверного проекта, см. `todo/server-rework.md`) — или переписывать на языке фронтенда (Node/TS),
  чтобы весь стек был в одной экосистеме.
- **Структура репозиториев:** монорепо (клиент + сервер вместе) или раздельные репозитории, как
  сейчас (`GwentOnline` + `ServerForGwent`)?
- **Хостинг** под хобби-проект — что реалистично на этом этапе (грубо, детальнее это уже
  `todo/deployment.md`).
